# 🏨 Hotel Cisne Azul - Landing Page

Uma landing page institucional, moderna e totalmente responsiva desenvolvida para o **Hotel Cisne Azul**, localizado em Sidrolândia - MS. O projeto foi estruturado com foco em conversão (reservas), excelente experiência de usuário (UX) e alta performance.

---

## ✨ Funcionalidades Principais

*   **Design High-End Minimalist:** Cores institucionais sóbrias (azul escuro e dourado) que transmitem elegância e sofisticação.
*   **Galeria de Acomodações Dinâmica:** Slider interativo para exibição dos quartos, com ajustes e correções específicas para dispositivos móveis.
*   **Grade de Serviços:** Apresentação clara dos benefícios inclusos (Wi-Fi, Café da manhã, Atendimento 24h).
*   **FAQ Inteligente (Sanfona):** Seção de perguntas frequentes desenvolvida utilizando apenas HTML5 nativo (`<details>` e `<summary>`), garantindo leveza e acessibilidade sem dependência de scripts pesados.
*   **Foco em Conversão:** Botões de chamada para ação (CTA) integrados diretamente para o WhatsApp de reservas.
*   **Efeito Scroll Reveal:** Elementos surgem suavemente na tela à medida que o usuário navega pela página.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais (Vanilla Stack) para garantir o máximo de velocidade de carregamento:

*   **HTML5:** Estrutura semântica e SEO-friendly.
*   **CSS3:** Estilização customizada com variáveis de ambiente (`:root`), Grid Layout, Flexbox e Media Queries personalizadas para dispositivos móveis.
*   **JavaScript (Vanilla):** Lógica do slider de fotos, integração do WhatsApp e animações de scroll.
*   **Google Fonts:** Tipografia utilizando a fonte *Montserrat*.
